The Lost Ingredients

Ten ingredients. Ten trials. One forgotten spell.

The Story

The night of Halloween was supposed to be a night of celebration. But deep within the forgotten forest, something went terribly wrong.

Morgana, the last Guardian of the Forbidden Grimoire, was preparing the Eternal Potion, an ancient creation capable of restoring balance between the magical and human worlds.

Just as she began the final incantation, the Grimoire trembled. Its pages turned black, its symbols shattered, and a mysterious force corrupted the ancient spells written within it.

In a flash of green fire, the potion ingredients vanished.

Dragon Blood was lost. Moon Dust faded into darkness. The Phoenix Feather disappeared. One by one, all ten ingredients were scattered across a maze of corrupted spells, hidden behind challenges that only the sharpest minds could overcome.

Without these ingredients, the Eternal Potion could never be completed. And without the potion, the curse spreading through the forest would become irreversible.

Morgana has searched for answers, but the Grimoire offers only one final message:

“Only those who understand the logic of magic can restore what has been lost.”

Now, she turns to you.

You are not ordinary visitors. You are the chosen apprentices, summoned to enter the corrupted Grimoire and recover its missing ingredients.

But beware: magic does not respond to guesses. Every spell follows a logic, every symbol hides a pattern, and every mistake may lead you further into darkness.

Ten challenges stand between you and the lost ingredients.

Solve them. Recover the magic. Prove that your minds are worthy of the Forbidden Grimoire.

The Ten Challenges

Each corrupted fragment hides one challenge. Solve it — prove the magic works — and its ingredient returns to Morgana's collection.

The Greatest Power. Numbers sleep in rows upon the walls of the Dragon's Cave. Some of them are perfect powers — a smaller number multiplied by itself again and again (2 × 2 = 4, 3 × 3 × 3 = 27, 10 × 10 × 10 = 1000). The dragon wakes only for the largest such number.

Write a function greatestPower(nums) that returns the largest number in the array that is a perfect power, or -1 if the cave guards none. A number n is a perfect power when n = baseexponent for integers base ≥ 1 and exponent ≥ 2. Note that 1 counts, since 1 = 1².

Examples

  • [2, 7, 3] → -1 — the cave is empty
  • [4, 9, 16] → 16 — 16 = 4²
  • [27, 25, 8] → 27 — 27 = 3³
  • [1, 2, 3] → 1 — 1 = 1²
  • [999999999, 1000000000] → 1000000000 — 1000³

Constraints

  • 1 ≤ nums.length ≤ 10000
  • 1 ≤ nums[i] ≤ 10¹²

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as greatestPower(nums), or the magic will not answer.

The Moon's Tithe. Morgana has gathered the scattered Moon Dust into piles. Each night the moon draws dust from a single pile at a fixed rate of r grams; if a pile holds fewer than r grams, the moon takes what remains and the night ends — it never carries leftover effort to another pile. The moon vanishes after the given number of nights.

Write a function minMoonRate(piles, nights) that returns the smallest integer rate r that empties every pile within nights nights. A pile of p grams takes ⌈p / r⌉ nights.

Examples

  • [3, 6, 7, 11], 8 → 4 — 1+2+2+3 = 8 nights, exactly enough
  • [30, 11, 23, 4, 20], 5 → 30 — one pile a night, so the biggest pile sets the floor
  • [30, 11, 23, 4, 20], 6 → 23 — rate 22 would need 7 nights
  • [5, 5], 2 → 5 — two piles, two nights
  • [312884470], 968709470 → 1 — more nights than dust

Constraints

  • 1 ≤ piles.length ≤ 10⁴
  • 1 ≤ piles[i] ≤ 10⁹
  • piles.length ≤ nights ≤ 10⁹

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as minMoonRate(piles, nights), or the magic will not answer.

The Corrupted Garden. Morgana's herb garden has been shattered into a grid of plots. Every night, the herb grows outward from where it already lives into the four neighbouring plots — up, down, left and right.

Each plot is one of:

  • 0 — stone: the herb cannot pass
  • 1 — fertile soil: grows in 1 night
  • 2 — herb: already growing here (starts at night 0)
  • 3 — cursed thorns: takes 2 nights to push through, and must still be covered

Write a function herbSpreadNights(grid) that returns the number of nights until every soil and thorn plot is covered, or -1 if some plot can never be reached. Return 0 if there is nothing left to cover.

Examples

  • [[2,1,1],[1,1,0],[0,1,1]] → 4 — the far corner takes 4 nights through soil
  • [[2,1,1],[0,1,1],[1,0,1]] → -1 — the bottom-left soil is walled off by stone
  • [[2,3,1]] → 3 — 2 nights to break the thorns, then 1 through soil
  • [[2,3,3],[3,3,1]] → 5 — crawling through a nest of thorns
  • [[2,1,2],[1,1,1]] → 2 — two herbs grow toward each other

Constraints

  • 1 ≤ rows, cols ≤ 200 (rectangular grid)
  • every value is 0, 1, 2 or 3
  • return -1 only when a soil or thorn plot is truly unreachable

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as herbSpreadNights(grid), or the magic will not answer.

The Phoenix's Flame. The phoenix is reborn once per night, and each rebirth records an ember strength — positive for a bright rebirth, negative for a cold one. A run of consecutive nights is a single flame, and its might is the total of those nights' ember strengths.

Write a function maxPhoenixFlame(embers) that returns the greatest total of any contiguous, non-empty run of nights. If every night is cold (all embers negative), the phoenix still burns once — return the largest single ember.

Examples

  • [3,-2,4,-1,2,-5,4] → 6 — 3 + -2 + 4 + -1 + 2
  • [-2,1,-3,4,-1,2,1,-5,4] → 6 — 4 + -1 + 2 + 1
  • [1,2,3,4] → 10 — the whole run
  • [-3,-1,-7] → -1 — all cold; take the least cold night
  • [1000000000,-1,1000000000] → 1999999999

Constraints

  • 1 ≤ embers.length ≤ 100000
  • -10⁹ ≤ embers[i] ≤ 10⁹
  • the run must be non-empty and contiguous

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as maxPhoenixFlame(embers), or the magic will not answer.

The Unbroken Web. The venom is stored as strands, each marked with an integer potency. A run is a set of potencies that are consecutive whole numbers — 1, 2, 3, 4 is a run of length 4 — no matter where they hang in the web or how far apart they are.

Write a function longestWebRun(strands) that returns the length of the longest such run hidden among the strands. The order of the strands does not matter.

Examples

  • [100,4,200,1,3,2] → 4 — 1, 2, 3, 4
  • [0,3,7,2,5,8,4,6,0,1] → 9 — 0 through 8
  • [1,2,0,1] → 3 — 0, 1, 2 (the duplicate 1 does not help)
  • [-3,-2,-1,0,1] → 5 — potencies may be negative
  • [10,5,12,3,55,11,4,13] → 4 — either 3,4,5 or 10,11,12,13
  • [1,3,5,7] → 1 — no neighbours; every run has length 1
  • [1,1,1] → 1 — duplicates are still a single node

Constraints

  • 1 ≤ strands.length ≤ 100000
  • −10⁹ ≤ strands[i] ≤ 10⁹
  • the run must be made of consecutive whole numbers; strands may repeat

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as longestWebRun(strands), or the magic will not answer.

The Haunted Corridor. The corridor is a line of chambers. Each chamber holds an echo count — positive for a warm spirit, negative for a chilling draft. A restless stretch is a contiguous run of chambers whose echoes add up exactly to the séance's target resonance.

Write a function hauntedStretches(echoes, target) that returns how many such stretches exist. Stretches may overlap. A single chamber counts. Echoes may be negative or zero.

Examples

  • [1,1,1] with target 2 → 2 — two overlapping stretches
  • [1,2,3] with target 3 → 2 — [3] and [1,2]
  • [3,4,7,2,-3,1,4,2] with target 7 → 4
  • [1,-1,0] with target 0 → 3 — [0], [1,-1], [1,-1,0]
  • [0,0,0] with target 0 → 6 — every stretch sums to 0
  • [1,2,3,-3,-2,-1] with target 0 → 3
  • [-1,-1,-1] with target -3 → 1 — the whole corridor
  • [5] with target 0 → 0 — a lone chamber of 5 misses

Constraints

  • 1 ≤ echoes.length ≤ 100000
  • −10⁹ ≤ echoes[i] ≤ 10⁹ and −10⁹ ≤ target ≤ 10⁹
  • stretches must be contiguous and may overlap; one chamber is allowed

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as hauntedStretches(echoes, target), or the magic will not answer.

The Missing Facet. A shard bears facets numbered 0 up to n, one for each number — but one facet has been lost. You are given facets, an array of n distinct numbers drawn from the range 0 … n.

Write a function missingFacet(facets) that returns the one number that is missing. There is always exactly one.

Examples

  • [3,0,1] → 2 — the range is 0…3, so 2 is gone
  • [0,1] → 2 — the range is 0…2
  • [9,6,4,2,3,5,7,0,1] → 8 — the range is 0…9
  • [0] → 1 — the range is 0…1
  • [1] → 0 — the range is 0…1
  • [0,1,2,3,4,5,6,8] → 7 — the range is 0…8
  • [1,2,3] → 0 — the first facet is gone
  • [2,0,1] → 3 — the last facet is gone

Constraints

  • 1 ≤ facets.length ≤ 100000
  • the n values are distinct and each lies in 0 … n
  • exactly one number from 0 … n is absent — it may be 0 or n

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as missingFacet(facets), or the magic will not answer.

The Vampire's Reflection. A scroll records a vampire's fang marks as one long string. To read a true mark sequence, ignore every character that is not a letter or a digit, treat upper and lower case as the same, and check whether what remains reads the same forwards and backwards.

Write a function isMarkedPalindrome(marks) that returns true if the sequence is true, otherwise false. An empty result (no letters or digits at all) counts as true.

Examples

  • "A man, a plan, a canal: Panama" → true
  • "race a car" → false
  • "Was it a car or a cat I saw?" → true
  • "No 'x' in Nixon" → true — quotes and spaces are noise
  • "0P" → false — digits and letters compare as characters
  • "ab_a" → true — the underscore is noise, leaving aba
  • "1a2" → false
  • "12321" → true — digits alone count
  • "..a.." → true — only a remains
  • " " → true — nothing but noise remains
  • "aA" → true — case is ignored
  • "" → true — empty is true

Constraints

  • 0 ≤ marks.length ≤ 100000
  • letters and digits count; spaces, punctuation and symbols are ignored
  • the comparison is case-insensitive

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as isMarkedPalindrome(marks), or the magic will not answer.

The Weighted Basket. Each forbidden mushroom has a weight. The basket can carry at most limit total weight. You may take any subset of the mushrooms, each at most once.

Write a function maxSpores(weights, limit) that returns the largest number of mushrooms whose weights sum to at most limit. If even the lightest mushroom exceeds limit, the basket stays empty — return 0.

Examples

  • [1,2,3,4,5] with limit 10 → 4 — 1+2+3+4 = 10
  • [5,5,5] with limit 10 → 2 — two fit, three do not
  • [10] with limit 5 → 0 — too heavy
  • [1,1,1,1] with limit 4 → 4 — all four fit exactly
  • [3,1,2] with limit 3 → 2 — 1+2 = 3
  • [0,0,0] with limit 0 → 3 — weightless mushrooms always fit
  • [7] with limit 7 → 1 — fits exactly
  • [2,3,4] with limit 6 → 2 — 2+3 = 5; adding 4 overflows

Constraints

  • 1 ≤ weights.length ≤ 100000
  • 0 ≤ weights[i] ≤ 10⁹ and 0 ≤ limit ≤ 10⁹
  • each mushroom may be taken at most once; only the count matters, not the total weight

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as maxSpores(weights, limit), or the magic will not answer.

The Final Circuit. Dark Matter cannot be seen — only felt. There are n fragments, and the pull between fragment i and fragment j is cost[i][j]. The ritual must visit every fragment exactly once, then close the loop back to where it began.

Write a function darkMatterCircuit(cost) that returns the smallest possible total pull of such a closed circuit. The circuit may begin at any fragment. cost is a symmetric n × n grid with zeros on the diagonal; a single fragment costs 0.

Examples

  • [[0]] → 0 — a single fragment needs no travel
  • [[0,7],[7,0]] → 14 — there and back
  • [[0,3,1],[3,0,2],[1,2,0]] → 6 — 0→1→2→0 = 3+2+1
  • [[0,10,15,20],[10,0,35,25],[15,35,0,30],[20,25,30,0]] → 80
  • [[0,41,60,10,41],[41,0,5,12,25],[60,5,0,39,48],[10,12,39,0,12],[41,25,48,12,0]] → 112 — nearest-neighbour would give 116
  • the five-fragment matrices above are the smallest that break greedy

Constraints

  • 1 ≤ n ≤ 13
  • 0 ≤ cost[i][j] ≤ 1000, symmetric, with 0 on the diagonal
  • every fragment must be visited exactly once, and the circuit must close

⚠ Name it exactly. The Grimoire calls your function by name — it must be defined as darkMatterCircuit(cost), or the magic will not answer.

⚠ This is the Super Hard trial. Trying every visiting order is n! routes: at n = 13 that is about 6 billion, far beyond the Grimoire's patience — and one hidden test is exactly that size, so a factorial solution will time out. Remember the cheapest way to cover each subset of fragments and stop on each fragment — 2ⁿ · n² — and it is instant.

Trial II

The Potion Factory

Morgana has her ten ingredients back. Now the factory must be rebuilt — not in stone and smoke, but in HTML, CSS, JavaScript and Bootstrap. This trial is judged on what you build and how it looks.

  • HTML · CSS · JS · Bootstrap
  • No AI
  • Frontend only

The Story

With the ten ingredients recovered, Morgana carried them down to the old factory beneath the tower — and found it ruined.

The dark force had torn the plans from the walls. No apprentice could find the ingredients now: there was no page to show them, no shelf to hold them, and no way to tell which ones were still missing.

Morgana cannot rebuild it herself — her hands are busy keeping the Grimoire sealed. So she hands you the plans and the artwork, and asks for one thing: a page that shows every ingredient, and shows them well.

What You Must Build

  1. A hero section. Open the page with a full-width hero: the event title, a line of the story, and a clear call to action.
  2. All ten ingredients. Every single ingredient has to appear — none may be left out.
  3. An attractive UI/UX. Show the ingredients with taste: a card grid, a carousel, modals, hover effects, filters — your choice. Make people want to click.
  4. A page that works everywhere. Desktop, tablet and phone. Nothing may overflow, break or disappear.

The Rules of This Trial

  • Not allowed

    No AI. Do not use ChatGPT, Copilot or any other AI assistant for this trial. Every line of markup, style and logic has to be written by you.

  • Required

    HTML, CSS, JavaScript and Bootstrap. Build the page with these four tools — and nothing that generates the page for you.

  • Required

    Design it yourself. Layout, typography, colour and animation are all part of the score. Aim for something that looks good, not just something that runs.

The artwork is provided

You do not have to draw anything. All ten ingredient images are supplied with the trial — each one a 500 × 500 SVG you can drop straight into your page. The story illustrations arrive as empty frames: keep the frames where they are and drop the artwork in when it is given to you.

Your Page Must Contain

  • A hero section
  • All ten ingredients, with their images
  • The name of each ingredient
  • Somewhere to read more about each one
  • Pictures placed in the story frames
  • Responsive layout on every screen size

Build it once, build it well — and the factory will breathe again.

Trial III

Protect the Grimoire

The factory is built and the ten ingredients are back inside it — but its door is wide open. This final trial is about the lock: an account, a passphrase, and a guard that turns the dark force away.

  • JS or PHP backend
  • Any database
  • Hashed passwords
  • No AI

The Story

The factory was rebuilt, and for one quiet night the ten ingredients were safe inside it.

Then word travelled beyond the Whispering Woods. The same dark force that tore the protective enchantment apart on that stormy Halloween night felt the old magic stirring again — and it began to gather at the tower’s door.

A page is not a wall. Anyone who found the factory could walk in, lift an ingredient from the shelf and carry off a piece of the Eternal Spell. The Grimoire had lost its protection once; Morgana would not let it lose it twice.

She remembered the old enchantment: no one entered the tower without the words that opened it. That spell is gone, so it has to be built again — in code this time. A door with a lock, a passphrase only the keeper knows, and a guard that asks for it at every threshold.

And whatever you do… do not leave the passphrase written where anyone can read it.

What You Must Build

  1. A registration page. A new keeper creates an account with a username or email and a passphrase.
  2. A login page. The keeper enters their passphrase and is let in — and turned away if it is wrong.
  3. A protected factory. The factory page and its ten ingredients open only for a logged-in keeper. Anyone else is sent back to the login page.
  4. A real backend. Accounts are stored, credentials are checked and the session is remembered — all on the server, not in the page.

The Rules of This Trial

  • Required

    JavaScript or PHP for the backend. Node.js, plain PHP or a framework of either — nothing else. The whole lock must live on the server.

  • Required

    Any database you want. MySQL, SQLite, PostgreSQL, MongoDB — whichever you are comfortable with. It only has to hold the accounts.

  • Required

    Passwords must be hashed. Never store a passphrase in plain text. Hash it before it is saved (bcrypt, Argon2 or PHP’s password_hash) and compare the hash at login.

  • Not allowed

    No AI. Do not use ChatGPT, Copilot or any other AI assistant for this trial. Every line — frontend, backend and query — has to be written by you.

What counts as protected

Opening the factory page directly must not work for a stranger. If a visitor who is not logged in can type the address and see the ingredients, the door is not locked — hiding the link is not the same as guarding the page.

Your Build Must Contain

  • A registration page
  • A login page
  • The factory locked behind the login
  • Passwords stored only as hashes
  • A session that survives a page reload
  • Logout that closes the session
  • Access denied to anyone not logged in
  • The ten ingredients still visible once inside

A door is only a door if it is locked.
